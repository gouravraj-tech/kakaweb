# Kaka Cafe Bengaluru Web Application

Official web application for **Kaka Cafe Bengaluru** — Authentic North Indian & Royal Rajasthani Cuisine in Yelahanka, Bengaluru.

## Highlights
- **Authentic Heritage Menu**: Dal Bati Churma, Stuffed Tawa Parathas, Punjabi Rasoi, Sindhi specials & Royal Thalis.
- **Interactive Modals**: Table Reservation, Order Online (Swiggy / Zomato / Direct WhatsApp), and The Kaka Group Catering inquiries.
- **Responsive Design**: Tailored for mobile, tablet, and desktop viewports with bottom navigation dock on mobile.
- **Local SEO & Schema Markup**: JSON-LD Structured Data for LocalBusiness (Restaurant & CateringService).

## Tech Stack
- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS + Custom Heritage Typography (Cinzel, Marcellus, Plus Jakarta Sans)
- **Icons**: Lucide Icons
- **Animation & Effects**: Framer Motion & Canvas Confetti

## Getting Started

### Installation
```bash
npm install
```

### Development Server
```bash
npm run dev
```

### Production Build
```bash
npm run build
```

### Preview Build
```bash
npm run preview
```
